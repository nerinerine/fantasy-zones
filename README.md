# fantacy zones
power toys中fancy zones的独立简化版本，c++实现，低内存、低cpu占用

使用另一个独立应用生成配置文件

## 使用例：
图先欠着

## 构建
1. 安装[xmake](https://github.com/xmake-io/xmake)、[windows sdk](https://learn.microsoft.com/en-us/windows/apps/windows-sdk/downloads)、[git](https://git-scm.com)和clang
2. `git clone`
3. `xmake f && xmake build`
